How to Manually Add Your PDFs

Step 1: Put your PDF file in the repository

In your GitHub repository, create a folder called pdfs/ and upload your actual PDF (e.g., pdfs/my_notes.pdf).

Step 2: Add an entry into RESOURCES in this file

Open index.html, scroll down to the bottom where you see const RESOURCES = [ ... ];, and add your file entry:

{
  id: "my-first-pdf",
  title: "Your Document Title",
  category: "Notes",
  description: "Brief summary or description of the document.",
  filePath: "pdfs/my_notes.pdf",
  fileSize: "1.5 MB",
  date: "Oct 2026",
  tags: ["Subject", "Topic"]
},

Step 3: Commit and Push

Commit your changes to GitHub. Your website on GitHub Pages will automatically update with the new resource!
